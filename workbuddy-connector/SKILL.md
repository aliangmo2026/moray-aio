# MoRay AIOps 探针（moray-aio）— WorkBuddy 连接器技能

安装本连接器后，你可以用自然语言让我做**只读**的本机运维诊断。所有操作都受白名单和沙箱保护：我能"看"，但不能"改"——不会改配置、不会启停服务、不会连白名单之外的主机。

## 我能帮你做的 9 件事

### 1. 看日志尾巴 — `log_tail`
> "帮我看下 `D:\MoRay\logs\moray.err.log` 最近 50 行"
> "日志最后 20 行里有没有 timeout？"

读取指定日志文件末尾若干行，按时间升序返回，可选关键字过滤。文件必须位于只读白名单（`MORAY_AIO_READONLY_ROOTS`）内。

### 2. 按正则搜日志 — `log_grep`
> "最近 10 条 ERROR 日志是什么？"
> "在日志里搜一下 `Connection refused` 出现了多少次"

对日志尾部窗口做正则匹配，返回命中的行。默认最多返回 100 条。

### 3. 列目录 — `list_files`
> "日志目录下都有哪些文件？"
> "看看 `D:\MoRay\logs` 里哪个文件最大"

列出白名单目录下的文件名和元数据（大小、修改时间），只看名字，不读内容。

### 4. 聚合滚动日志 — `log_rolling_tail`
> "把轮转日志合起来看最近 50 行"

当日志被 logrotate 切成 `moray.err.log.1`、`.gz` 等多个文件时，跨文件聚合取最新尾部。

### 5. 测端口连通性 — `port_check`
> "帮我查一下本地 6379 端口通不通"
> "8080 端口响应快吗？"

TCP 探测指定主机端口，返回 open/closed 和延迟（毫秒）。主机必须在探测白名单内（默认仅 `127.0.0.1` / `localhost` / `::1`）。

### 6. 看进程列表 — `process_list`
> "现在有哪些 python 进程？"
> "找一下名字里带 ollama 的进程"

列出本机进程（PID/名称/内存），支持按名称正则过滤，数量有上限，防止刷屏。

### 7. 查磁盘占用 — `disk_usage`
> "C 盘还剩多少空间？"
> "`D:\MoRay` 这个目录占了多少磁盘？"

查询白名单路径的磁盘/目录使用情况（总量、已用、可用、百分比）。

### 8. 查 Windows 服务状态 — `windows_service_status`
> "Nginx 服务现在是什么状态？"
> "MySQL 服务起来了吗？"

查询 Windows 服务的运行状态。**只查询，永远不启动/停止/重启任何服务。**

### 9. 沙箱里跑只读 Python — `execute_safe_python`
> "帮我算一下最近 7 天日志里每天的错误数分布"
> "用 Python 把这几个数字做个简单统计"

在进程隔离沙箱中执行 Python 片段做分析计算：静态审查拒绝危险 AST 节点、空 builtins、硬超时（默认 3 秒）。不能 import 网络/文件系统模块，不能碰白名单外路径。

## 我不会做的（硬边界）

- ❌ 修改、删除、写入任何文件
- ❌ 启动/停止/重启服务或进程
- ❌ 连接白名单之外的主机（防 SSRF）
- ❌ 执行 shell 命令
- ❌ 读取白名单根目录之外的任何路径（fail-closed，默认 `D:\MoRay\logs`）

## 提问小贴士

- 给出**具体路径和端口**，诊断会又快又准。
- 排障建议从"看日志"开始：先 `log_tail`/`log_grep` 定位错误，再 `port_check`/`process_list` 交叉验证。
- 日志大文件不用担心：扫描字节数有上限（`MORAY_AIO_MAX_SCAN_BYTES`，默认 5 MB），且有每分钟调用限流。
